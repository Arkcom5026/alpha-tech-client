# Alpha Design System — Foundation Slice

This directory contains the clean executable foundation of the replacement design system.

Included in this slice:
- semantic CSS tokens with light/dark values
- Button and IconButton
- Input and Textarea
- Badge and Spinner
- Page, Stack, and Card layouts
- Alert, EmptyState, and LoadingState feedback surfaces
- a public barrel export at `src/design-system/index.js`

No legacy component has been moved or deleted. No feature module has been migrated in this slice.
